# 携帯自販機

自販機の当たりを当てるだけのゲーム。ボタンを押して、4けたの数字がそろえば当たり。

- 遊ぶ：https://nasubi-no-oniwa.github.io/jihanki/
- 確率：当たりは 2%（50本に1本。景品表示法から決まる、本物の自販機の上限）。当たりは虹の7色で、どの色も同じ出やすさ
- 当たりの演出：7色それぞれ別もの（赤＝大噴火・橙＝夏祭り・黄＝一攫千金・緑＝大豊作・青＝大波・藍＝宇宙へ・紫＝降臨）。7色そろうとコンプの演出
- 外れの演出：100種類（`data.js` の `LOSE`）。リーチ・すべり・熱い予告などは見せ方だけで、当たる確率は変わらない
- ファイル：`index.html`（画面・流れ・通信・動画）、`data.js`（決まりごと・ことば・くじ）、`draw.js`（自販機と外れの絵）、`win.js`（当たりの絵）、`snd.js`（音）
  - 絵と音は「買ってからの秒」だけで決まる書き方。動画を作るときは同じ時刻をもう一度たどる
  - ファイルどうしは `?v=番号` をつけて読みこむ。直したら、全部の番号をそろえて上げる
- 記録：通算の本数・当てた色は、遊ぶ人のブラウザの中（`jh_s`）。引き継ぎコード（8文字）で別のブラウザへ移せる
- Firebase：ft-red の `jihanki` の下（`database.rules.jihanki.json` を上げると自動で反映。鍵は `FT_RED_SERVICE_ACCOUNT`）
  - `c`＝色ごとの「当てたことがある人数」とコンプした人数（数だけ。1人1色1回）、`u`＝数えた印、`f`＝みんなの当たり（1人1件・新しいもので上書き）、`x`＝引き継ぎコード
- 広告：結果画面とタイトル画面（なすびのお庭の決まりどおり。スマホだけ。読みこみ直しは場所ごとに30秒に1回まで（ほかの作品と同じ）。`?adcheck=1` をつけて開くと、広告の枠の中の様子を画面に字で出す。`?noad=1` で広告なし）
- 試験：`test/rules-test.mjs`（ルール。GitHub の上で動く）。`index.html?test&step` で通信なし・手動で時間を進める形になる
